# Code of conduct

Sloucher follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussions about the work. Harassment, insults and personal attacks
aren't welcome in issues, pull requests or anywhere else the project lives.

**Reporting a problem:** use [GitHub's report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
on the comment or issue, or contact the maintainer through [karthikeyanumesh.com](https://karthikeyanumesh.com).
Reports are handled privately and taken seriously.
